🌿 About the Project

The AI Agricultural Yield Prediction System helps users estimate crop yield based on selected farm and agricultural conditions.

The system combines a trained Machine Learning model with a separate weather-analysis module to provide additional information about the selected crop.

🤖 About the AI Model

The system uses a Random Forest Regression model for agricultural yield prediction.

Random Forest combines multiple decision trees to make predictions. This allows the model to learn relationships between agricultural inputs and crop yield.

The model was trained using 1,500 agricultural records .

📊 Model Performance

The model was evaluated using a separate test set and 5-fold cross-validation.

350.84 MAE (kg/ha)
496.21 RMSE (kg/ha)
0.8809 Test R²
0.8976 5-Fold CV R²

☀️ Weather Analysis

Weather information is obtained separately from the Machine Learning prediction.

Temperature, rainfall and humidity are analyzed and compared with preferred weather ranges defined for the selected crop.

⚠️ Limitations

  • The prediction is an estimate based on information provided by the user.
  • Model predictions depend on patterns learned from the training dataset.
  • Soil properties such as pH and nutrient levels are not currently required from users.
